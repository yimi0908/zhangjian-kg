使用说明

1. 系统概览

本平台旨在通过可视化技术展现张謇相关历史工业与地方文献的关联网络。数据来源于原始档案及表格数据提取的三元组，力求还原历史资源的多维关系。

2. 操作指南

数据加载：因本图谱包含约3万多个实体与6万多条关系，首次访问时大数据集载入需一定时间，请在浏览器加载完成后稍作等待。

视图探索：

  • 初始视图：为保证性能，系统默认仅展示关联度最高的核心实体。
  • 节点交互：单击节点可查看详细元数据；搜索节点可展开其深度关联的资源网络。
  • 筛选功能：进行"关系类型筛选"时，建议配合"实体类型"筛选使用。

快捷操作：

  • 力导向控制：若图谱布局波动剧烈，可使用底部的"冻结/运行"按钮（暂停图标）锁定节点位置，方便阅读细节。
  • 视图重置：按键盘"R"键或点击"重置布局"按钮，可快速回到初始概览状态。
  • 图像导出：通过"导出图片"按钮可将当前视窗保存为本地 PNG 文件。

3. 数据与性能说明

精度声明：本图谱数据依据原始 Excel 表格自动分类提取。受限于历史档案的复杂性，少量关系提取或节点分类可能存在偏差，内容仅供学术参考。

性能与兼容性：

  • 推荐使用 Chrome、Edge 或 Firefox 最新版本以获得最佳显示效果。
  • 搜索与筛选功能涉及大规模实时拓扑计算，操作时如遇短暂延迟请耐心等待。
  • 若页面显示异常，请按下 Ctrl + F5 (Windows) 或 Cmd + Shift + R (Mac) 强制刷新缓存。

感谢您使用张謇八大资源知识图谱平台，如在探索过程中有学术建议，欢迎随时反馈。
