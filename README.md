# 张謇八大资源知识图谱平台 (Zhang Jian Knowledge Graph Platform)

本仓库致力于构建张謇研究的数字化基础设施。通过语义网技术与大规模网络可视化，将分散的工业史、地方志及档案文献整合为互联的知识图谱，旨在为张謇研究提供创新的数字人文分析工具。

## 🚀 项目功能
* **大规模网络可视化**：基于 HTML5 Canvas 和 D3.js，实现对数万节点及关联关系的丝滑渲染。
* **多维知识过滤**：支持基于“实体类型”与“关系类型”的联动组合筛选，实现对历史人物、机构、事件的深度切片。
* **交互式探索**：支持节点深度联想加载、路径查询与搜索定位。
* **高性能架构**：采用分片异步加载策略，在保证数据全量覆盖的同时兼顾加载速度。

## 🛠 技术栈
* **前端渲染**：[D3.js](https://d3js.org/) + Native HTML5 Canvas
* **数据存储**：JSON 结构化分片存储 (兼容 RDF/Turtle)
* **部署平台**：GitHub Pages

## 📖 使用指南
访问 (https://yimi0908.github.io/zhangjian-kg/) 即可查看交互式图谱。
* **探索**：单击实体查看详情；双击实体放大。
* **筛选**：使用左侧面板进行实体与关系多类型筛选。
* **工具**：底部工具栏支持缩放、冻结布局、隐藏标签；顶部导出图片。
* **搜索**：顶部搜索栏快速定位实体，展开关联网络（部分）。
